# Unity 0.2.3 Beta · Minecraft Java 26.2

Unity 可以直接加载 Fabric 官方发布的 `fabric-api-0.152.1+26.2.jar`。该版本与 Unity 26.2 原有样本使用的 Fabric 模块相同。安装时只需放入完整发行 JAR，Unity 自己发现内嵌模块、应用访问转换与 Mixin，并调用入口。游戏仍由 `mc.unity` 独立启动。[官方发行目录](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.152.1%2B26.2/)

## 安装完整 Fabric API

完整官方 JAR 随发行包放在 `standalone/vendor/`，可离线安装。将该 JAR 同时放入客户端与专服各自的 `mods` 目录，或运行 `Install-Unity-Fabric-API.cmd` 安装到本项目的两个默认实例。自定义实例可运行 `python tools/unity.py fabric-api --game-dir <实例目录>`。已有原始 JAR 时可以加 `--from-jar <官方发行文件>` 离线安装。

## 加载和网络

- 官方 JAR 的 43 个内嵌模块逐个按 SHA-256 锁定。客户端使用 43 个，专服使用适用的 36 个。完整模式中官方模块提供 Fabric API 类及其实现；Unity 的轻量接口用于未放入整包的实例。模组声明的 Loom 客户端专用文件只在客户端进入类索引和 ABI 预检。
- 官方包声明的泛型接口注入保留 JVM 泛型签名。模组可使用默认语言适配器的类、字段、方法入口，读取元数据自定义值、嵌套容器与 Minecraft 游戏资源。
- 在轻量模式中，Play 支持按方向注册编解码器、登录协商全局接收器、主线程收发和回复。同一标识符的去程与回程可使用不同数据类型。该模式在第一次登录协商后固定接收器；连接级动态注册与大包分片由完整模式中的官方 networking 模块提供。

## 配置重载与通用资源包

文件监听器只在锁内读取文件事件并取得待重载清单。模组回调在锁外运行，关闭会话先使旧任务失效，再等正在执行的回调结束。跨线程回归同时覆盖首次安装监听时的补扫和日常 Tick 轮询。

只含声明式资源和数据的通用包可以使用 Manifest 的 `Implementation-Version` 解析 FML 模板版本。客户端按资源包格式选择贴图和语言 overlay，专服按数据包格式加载函数和配方。实机探针在同一归档中分别验证客户端翻译与专服函数。

## 验收范围

完整模式逐模块校验原始字节、元数据版本和类的代码来源。客户端链接了 `net.fabricmc.fabric.api` 下适用的 700 个类文件，专服链接了 438 个（均不含 `package-info`）。另外通过实际类加载检验了官方 Mixin 配置声明的 Minecraft / Mojang 目标类，客户端 375 个、专服 220 个。联机测试以两个隐藏图形客户端验证进服、夜视快捷键、不同编解码器的双向包、资源重载、重启与背包回读。数据生成另起 JVM，执行 Fabric 声明的数据生成入口并核对生成的 JSON。[完整 API 验收](../evidence/0.2.3-Beta/full-fabric-api.json) · [轻量模式与混装验收](../evidence/0.2.3-Beta/candidate65.json)

完整模式的兼容基线为上述官方发行件。本版的模块覆盖、类链接和实机玩法是三项不同的证据。每个 API 方法的所有参数组合、其他 Fabric API 版本、第三方语言适配器与任意整合包组合，均超出此次测试范围。
